Връзка с GitHub

Задачите се пазят във файла tasks.json в хранилището. За да ги променяте, всеки от вас въвежда свой GitHub токен веднъж на всяко устройство. Токенът остава само в този браузър.

Собственикът на хранилището ():
  1. Отворете GitHub → Fine-grained token.
  2. Repository access: Only select repositories → .
  3. Permissions → Repository → Contents: Read and write. Generate token.
Съавтор (добавен като collaborator):
  1. Отворете GitHub → Classic token.
  2. Отметнете само public_repo. Generate token.
